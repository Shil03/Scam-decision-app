# APP Shield: Authorised Push Payment Scam Decision Service

A decision service for the outbound payment path that assesses each payment for authorised push payment (APP) scam risk before release.

The requirements are in [docs/intent.md](docs/intent.md), the source of truth for this build. Build time is recorded in [TIMELOG.md](TIMELOG.md).

*Work in progress: built in gated steps (design, then engine, then API and persistence, then the scenario suite, then documentation).*
